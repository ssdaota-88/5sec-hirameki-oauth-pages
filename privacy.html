5秒ひらめき YouTube Automation

プライバシーポリシー

最終更新日: 2026年9月19日

1. 概要

本アプリは、5秒ひらめきチャンネル運営者自身がYouTube Shortsの制作・非公開アップロード・パフォーマンス分析を行うために使用する個人運営の管理ツールです。

2. 利用するGoogle APIとデータ

本アプリは、Google OAuth 2.0を通じてYouTube Data APIおよびYouTube Analytics APIを利用します。

  • YouTube upload: 生成した動画をYouTubeへ非公開でアップロードするために使用します。
  • YouTube readonly: 自分のチャンネル、動画、動画タグ、アップロード状況などを確認し、同日重複投稿を防止するために使用します。
  • YouTube Analytics readonly: 自分の動画の再生回数、平均視聴時間、いいね数等の集計指標を取得し、動画形式ごとのパフォーマンスを分析するために使用します。

3. Googleユーザーデータの利用目的

取得したGoogleユーザーデータは、次の目的に限定して使用します。

  • 動画を非公開でYouTubeへアップロードすること
  • 同じ日に同一パイプラインから複数動画がアップロードされることを防ぐこと
  • 自分のYouTube動画のパフォーマンスを分析すること
  • 分析結果を用いて今後生成するクイズ形式の比率を調整すること

取得したデータを広告配信、信用評価、第三者への販売、第三者向けプロファイリングには使用しません。

4. データの共有

Googleユーザーデータを第三者へ販売しません。また、本アプリの機能提供に必要な場合を除き第三者へ共有しません。

処理にはGoogle APIおよびGitHub Actionsを利用します。OAuthのRefresh Token等の認証情報はGitHub Actions Secretsに保存し、公開リポジトリのソースコードへ記載しません。

5. データの保存と保持期間

本アプリは、YouTube Analyticsから取得した集計データを実行時の処理に使用します。生成された動画や一部の実行結果はGitHub Actions Artifactとして一時保存され、通常3日で期限切れになる設定です。

OAuthのRefresh TokenはGitHub Actions Secretsに保存され、公開ページやログへ意図的に表示しません。

6. データの削除・アクセス解除

Googleアカウント側で本アプリへのアクセスを解除することで、OAuth認可を無効化できます。また、GitHub Actions SecretsからRefresh Tokenを削除することで、本アプリからGoogle APIへのアクセスを停止できます。

一時保存されたGitHub Actions Artifactは設定された保持期間経過後に削除されます。

7. Google API Services User Data Policy

本アプリによるGoogle APIから受け取った情報の利用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に準拠するものとします。

8. ポリシーの変更

本アプリの機能や利用するAPIに変更があった場合、本ポリシーを更新することがあります。更新日はこのページ上部に表示します。
